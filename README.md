# Marketing Campaign Deep Dive Dashboard

## Project Overview
This project analyzes customer marketing campaign data using Power BI.

## Key Insights
- Total Customers: 2240
- Average Income: 52.25K
- Response Rate: 15%
- Education-wise product spending analysis
- Age distribution analysis
- Customer response distribution
- Income vs Spending relationship

## Dashboard Features
- KPI Cards
- Scatter Plot
- Donut Chart
- Bar Chart
- Histogram
- Product Spending Analysis

## Tools Used
- Power BI Desktop
- Marketing Campaign Dataset
